# work-tools

Small tools for day-to-day work.

- [gh-img-resize](gh-img-resize/): Chrome extension to resize images in GitHub comments and PR descriptions.
- [pr-watch](pr-watch/): macOS menu bar app that alerts on GitHub PR activity. Build with `pr-watch/scripts/bundle.sh --install`.
- [taskfloat](taskfloat/): floating macOS task timer. Build and start with `taskfloat/build.sh`, or `tf` from the shell.
